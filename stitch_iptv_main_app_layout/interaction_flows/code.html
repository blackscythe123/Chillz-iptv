4. Long-list Performance

VIRTUALIZATION

Virtual List Rendering

To handle ~38,000 channels without freezing the browser, we employ windowing. Only the items currently visible in the viewport (plus a small buffer) are rendered in the DOM. As the user scrolls, items leaving the view are recycled and updated with new data.
